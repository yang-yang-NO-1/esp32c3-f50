# F50 v2 部署记录

2026-11-21 已在当时连接的 F50 替换温控、自启动和重启脚本。
旧脚本、状态和原约 78 MB 温控日志保存在该设备：

```text
/data/local/tmp/f50-fan-backup-20261121-182626/
```

如需回退，先核对并停止当前温控 PID，再恢复备份目录中的三个脚本和 `fan_state`，
最后启动旧温控程序。备份中的 `ufi_tools_boot.sh` 应恢复到 `/data/media/0/`。

部署时已验证：

- 三个已部署脚本与项目文件的 SHA-256 一致，设备端 `sh -n` 语法检查通过。
- 重复调用自启动入口后只有一个温控实例。
- 重启脚本可以停止旧实例并启动新实例，保留回差区间内的自动意图。
- 温度约 50.6℃时触发 OFF → ON。
- `PING` 返回 `OK PONG`，`STATUS` 返回 `OK STATUS FAN=ON`。
- 原大日志已归档到备份目录，新日志重新记录。
